# procyon
untethered re-jailbreak for iOS 10.0-10.3.4 (32bit)

# Information:
- Only 32bit devices are supported
- Installing can be done with [Socket - ios.cfw.guide](https://ios.cfw.guide/installing-socket) if un-jailbroken (or re-jailbreaking)
- Already jailbroken devices can install 'procyon untether' from the following repo: [https://lukezgd.github.io/repo](https://lukezgd.github.io/repo)
- The iPad 4 on iOS 10.3.2+ have a base success rate of 93%, meaning ~7% of the time it will not boot to SpringBoard and you will need to perform a manual reboot.
- CoolBooter Untetherer is ***not*** supported and will cause the device to boot to a blank screen.
- There is no warranty with this software, so use at your own risk.
